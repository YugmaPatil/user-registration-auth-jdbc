# User Authentication System

A console-based User Authentication System developed using Java, Maven, and MySQL.

## Features

- User Registration
- User Login
- Role-based access (ADMIN / USER)
- Admin menu
- View all users
- Delete users
- User profile management
- Update username and password
- Delete own account
- Session management
- MySQL database connectivity

## Technologies Used

- Java
- Maven
- MySQL
- JDBC
- Git & GitHub

## Project Structure

src/main/java
├── dao
├── model
├── service
├── util
└── main

## How to Run

1. Install Java and Maven.
2. Install MySQL.
3. Create the `auth_system` database.
4. Configure database credentials using environment variables.
5. Run the application using Maven.
